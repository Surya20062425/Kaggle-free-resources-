## Other Free Kaggle Resources

Beyond courses, Kaggle provides a full ecosystem of free tools and community resources:

### 1. Kaggle Notebooks
- **Free cloud-based Jupyter notebooks** (Python or R)
- Access to **free GPUs** (Tesla T4, P100) and **TPUs**
- Approximately **30 hours of GPU time per week** and **20 hours of TPU time per week** 
- Up to 12 hours of execution time per session
- 20 GB of working storage across notebooks 

### 2. Public Datasets
- Thousands of datasets in CSV, JSON, SQLite, and more
- Community discussion and code sharing on each dataset
- Ability to create and upload your own private datasets

### 3. Competitions
- **Beginner-friendly "Playground" competitions** (e.g., Titanic, House Prices)
- **Featured competitions** with real prizes and career recognition
- **Research competitions** for cutting-edge problems
- **Code competitions** for practical implementation challenges

### 4. Models Hub
- Access to a wide range of pre-trained ML models
- Filter by task (image classification, NLP, etc.), framework, and data type
- Guides on how to use models from start to finish 

### 5. Community & Discussion Forums
- Ask questions, share insights, and get feedback
- Network with millions of data scientists and ML engineers

### 6. Kaggle Benchmarks & Game Arena (2026)
- **Kaggle Benchmarks**: Over 70 verified AI leaderboards for transparent model evaluation
- **Kaggle Game Arena**: Let models compete head-to-head 

### 7. Hugging Face Integration
- Pull models and datasets directly from Hugging Face into Kaggle notebooks with pre-written code

## Kaggle Progression System (Free Tier Badges)

Kaggle recognizes your contributions through a **free tiered progression system** across four categories: Competitions, Datasets, Notebooks (Kernels), and Discussions. 

| Tier | How It's Earned |
|---|---|
| **Novice** | Join Kaggle |
| **Contributor** | Complete basic activities (e.g., run a notebook, comment) |
| **Expert** | Consistent quality contributions |
| **Master** | High-ranked performance or highly valued contributions |
| **Grandmaster** | Top-tier performance across multiple areas |

As of April 2025, out of 23.29 million accounts, only **612 users** have achieved Grandmaster status — making it a highly respected credential in the data science community.

## Bottom Line

Kaggle is **entirely free** to use for learning, competing, and building your portfolio.
